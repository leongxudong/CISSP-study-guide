# CISSP Eight-Domain Revision Map

Use this as a checklist for organising revision rather than as a replacement for the official ISC2 exam outline.

## Domain 1 — Security and Risk Management

Focus areas:

- CIA and security principles
- governance and policy
- risk management
- legal/regulatory concepts
- professional ethics
- security awareness
- business continuity fundamentals
- threat modelling concepts

## Domain 2 — Asset Security

Focus areas:

- information and asset classification
- ownership and custodianship
- handling requirements
- privacy
- retention
- data lifecycle
- secure destruction

## Domain 3 — Security Architecture and Engineering

Focus areas:

- security models
- secure design principles
- cryptography and PKI
- hardware/platform security
- physical security
- vulnerabilities in architectures and systems

High-value distinction: **Bell-LaPadula = confidentiality; Biba = integrity.**

## Domain 4 — Communication and Network Security

Focus areas:

- OSI/TCP-IP concepts
- network protocols
- secure network architecture
- segmentation
- wireless
- remote access
- network attacks and countermeasures

Understand why a protocol/control is used rather than memorising ports in isolation.

## Domain 5 — Identity and Access Management

Focus areas:

- identification, authentication, authorization and accounting
- access-control models
- provisioning/deprovisioning
- federation and SSO
- MFA
- privileged access
- identity lifecycle

## Domain 6 — Security Assessment and Testing

Focus areas:

- audit and assessment concepts
- vulnerability assessment vs penetration testing
- test strategies
- security metrics
- log/review concepts
- control testing

Know the objective and limitations of each assessment technique.

## Domain 7 — Security Operations

Focus areas:

- incident response
- logging/monitoring
- investigations
- change/configuration management
- patching and vulnerability management
- backups
- BCP/DR operations
- physical/operational security

Pay attention to sequencing and preservation of evidence.

## Domain 8 — Software Development Security

Focus areas:

- SDLC models
- integrating security into development
- requirements and threat modelling
- secure coding concepts
- testing approaches
- change/configuration management
- application vulnerabilities
- DevSecOps concepts

The important theme is building security into the lifecycle rather than treating testing as the only security activity.

## Revision rule

If you can recognise a term but cannot explain **what problem it solves, who is responsible for it, and where it belongs in the lifecycle**, the topic probably needs another pass.
